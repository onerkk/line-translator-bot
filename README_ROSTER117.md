# 更新 117：確認名單狀態提示

本包接續 CI116 更新，只包含本次有變更的檔案、說明及校驗檔。將三個 Python 檔案覆蓋到專案根目錄，提交、通過 CI 後重新部署即可。

## 這次修正

- 未取得完整名單或尚未完成群組人數核對時，顯示「名單完整性尚未確認」，不直接宣稱名單確定缺人。
- 已知還有多少人未取得身分時，明確顯示該人數。
- 有未回覆成員時，不再出現固定的「已知 0 人不代表全員了解」。
- 已辨識的應回覆成員都回覆、但名單完整性未知時，明確說明仍可能提醒全體；只有名單已核對完整且無待回覆者，才顯示本次應回覆成員已全數回覆。
- 舊版 CI116 安裝工具的測試改為核對其固定版本的還原結果，避免日後正常更新被誤判為舊安裝包不一致；備份、校驗、回復及功能檢查保留。

本次沒有變更翻譯引擎、提醒週期或停止判斷。新提示會出現在重新按「了解」或查詢後產生的新卡；已送出的卡片不會因更新程式而自動刷新。

## 已核對的實際行為

1. 有姓名名單，只能證明這些人已被辨識；不能僅從上方有 8 個未回覆姓名，認定全群已全部納入。
2. 程式在提醒時間核對成員及人數。確認名單完整、待回覆人數為零時，會停止後續提醒。若完整性仍未知，即使已知成員都回覆，仍可能繼續 @All。
3. 發起者不列入待回覆名單，不需要按「了解」才能結束。發起者自行按下時，仍可能出現在「已回覆」紀錄。
4. LINE 的群組人數 API 不計入本機器人；程式也會忽略帶 isSelf=true 的機器人提及。測試確認機器人不因此被加入已知成員，且不需要發起者或機器人回覆即可停止。
5. 排除待回覆名單，不等於排除 @All 通知。名單不完整時的 @All 會提醒全體，發起者與已回覆者也可能收到。能逐人點名時，才只標記待回覆者。

LINE 官方來源：
- 群組人數（不含官方帳號）與成員名單：https://developers.line.biz/en/reference/messaging-api/nojs/
- 成員身分來源與名單 API 權限：https://developers.line.biz/en/docs/messaging-api/getting-user-ids/

## 驗證

2023 項離線測試及 443 個子測試通過，全部 UI 測試通過。新增測試涵蓋 5 人回覆／8 人未回覆、未知總人數、明確缺人、完整與不完整名單下的全數回覆，以及發起者和本機器人的排除。

以上為程式檢查與隔離測試結果；尚未讀取正式群組資料或部署你的伺服器。
