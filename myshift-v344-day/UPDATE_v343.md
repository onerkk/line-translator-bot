# v343-taiwan（第三階段：台灣在地四季生態、霧、熱擾動 ＋ 實機回報修正）

只含變更檔，覆蓋 repo 根目錄即可；包內已含第一、二階段全部檔案。

## 實機回報修正
- **雨珠往上飄**：水珠在格子內的「停頓—滑落」擺動幅度大於整體下滑速度，偶爾會倒退向上。現在整體下滑速度固定大於擺動最大速度，水珠只會停頓、不會上行。
- **雨珠是一排黑球**：
  - 黑：夜晚折射到的天空本來就暗。現在每顆水珠有基本的灰藍底、亮邊與左上高光，夜間也看得出是透明水珠。
  - 一排：手機 GPU 片段著色器預設 mediump（半精度），亂數函式退化成同一列同值。兩個著色器改為可用時用 highp，亂數改為手機安全的算法。
- **全畫面光景卡顯示異常**：v341b 把卡片改成「透明視窗」，但它是在面板裡，透出來的只是面板模糊；程序化天空換掉景片後就只剩一片灰。現在卡片內原有的 `.scene-canvas` 重新啟用，每 0.25 秒畫入它在螢幕位置對應的即時天空＋前景（真的開一扇窗）。
- **白天／夜晚切換當機**：我這裡重現不了（軟體渲染下切換正常）。已做兩件事：GL 任一層 context lost 立刻退回 v341 畫法、單幀例外不會中斷迴圈；但如果你看到的是 Chrome 整頁「喔不」，那是 GPU 行程被砍，請把 `WxFx._debug()`（含 `skyGL`、`frameMs`）和當機前切的是哪個預覽貼給我。

## 第三階段
- `nature-taiwan.js`（新）：台灣平地四季生態全部程序化繪製，不用圖片素材。
  - 春：木棉（橘紅大花杯）、油桐（白色五瓣「五月雪」）；枝條在兩側。
  - 夏：鳳凰木（猩紅花瓣、羽狀複葉）；螢火蟲、樹蛙沿用。
  - 秋：台灣欒樹（黃花串→粉紅燈籠蒴果）、芒草（銀白花穗沿底部，隨風擺）。
  - 冬：落羽松（鏽褐羽狀枝）、東北季風（乾葉被橫掃、風線）；只有風大或寒流才飄，不再無風也慢慢落。
- `nature-effects.js`：四季飄落物、兩側植物改用上述素材；楓葉、櫻瓣不再使用（圖檔保留可自行刪）。雨天飄落物加速、風大橫飛。
- `sky-gl.js`：霧改為前景漂移霧帶（在觀者與景之間，隨高度變濃），熱浪改為畫面下半部的熱空氣扭曲（真的扭曲後方景象），雨絲、颱風雨帶、閃電也移到前景層並受文字遮罩保護。
- `index.html`、`sw.js`、`immersive-v341.css`：載入 `nature-taiwan.js`，版本 `343-taiwan`，30 個啟動檔 SHA 重算。

- 前景 GL 層現在在雨、霧、熱浪、閃電時啟用；實機卡的話回報 `frameMs`。
