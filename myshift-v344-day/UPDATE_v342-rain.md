# v342-rain（第二階段：雨、玻璃折射水珠、閃電照亮雲層）

建立在 v342-sky 之上；只含變更檔，覆蓋到 repo 根目錄即可。若還沒裝 v342-sky，直接裝這包也可以（內含第一階段全部檔案）。

## 變更檔
- `sky-gl.js`：
  - **雨**：天空層加三層遠中近雨絲（依風向斜落、依雨量增減），地平線方向加雨霧。颱風改為柔和漂移的雨帶，取代 v341 的硬邊斜長方形雨牆。
  - **閃電**：程序化主幹＋分支，從雲底劈下；雲層依距離閃電的遠近與厚度被「從裡面照亮」，天空只微亮，不再整片刷白。雷聲延遲與時序沿用原邏輯。
  - **玻璃水珠**（新前景 WebGL 層 `#nature-glass-gl`）：每顆水珠是會折射後方天空的凸透鏡（倒影縮小、邊緣折射、左上高光），沿玻璃斷續滑落，上方留下串珠狀水痕；數量隨雨量，傾斜隨風。文字保護遮罩（和 `#wxfx` 同一張）會上傳成貼圖，所以面板文字上不會有水珠。不下雨時這層整個隱藏，零成本。
- `nature-effects.js`：GL 啟用時停用舊的 drop.png 水珠、閃電 sprite、整頁閃光與颱風雨牆；原 2D 雨絲保留但數量減到 55%（近景層，與 GL 遠景雨互補）；`buildMask()` 會同步遮罩到 GL。退回條件不變：沒有 WebGL 就全部回到 v341 畫法。
- `immersive-v341.css`：`#nature-glass-gl` 定位（z-index 31，在 `#wxfx` 之下、介面之上）；reduced-motion 時隱藏。
- `index.html`、`sw.js`：版本 `342-rain`，快取名 `myshift-v342-rain`，29 個啟動檔 SHA 重算並 `--check` 通過。
- `scripts/check-atmosphere-v342.cjs`：「雨天在玻璃上有畫面」檢查改為同時計算 GL 玻璃層；dock 膠囊對齊改等最多 6 秒（軟體渲染下引擎時間走得慢）。

## 驗證（Headless Chromium + SwiftShader 軟體 WebGL，非實機）
- `node scripts/check-atmosphere-v342.cjs --swiftshader`：54 項通過 ×3 次，對比稽核 0 不合格。
- 單獨渲染目視：白天小雨、黃昏豪雨、日間雷雨閃電、夜間雷雨閃電、颱風、冬夜毛毛雨；遮罩區確認無水珠。

## 限制
- 水珠折射的是「天空」那一層，不是面板文字（HTML 無法被著色器取樣）；因為面板本來就是半透明玻璃，視覺上是合理的。
- 下雨時多一個前景 WebGL 層與每幀一次天空貼圖上傳（約 300×640），實機請觀察 `WxFx._debug().skyGL.glass` 與 `frameMs`；卡的話降「自然／輕柔」會減少水珠層數（3→2→1）。
- 第三階段（台灣在地四季生態、霧、熱擾動）還沒動，地面仍是 v341 的楓葉與植物。
